# Kingdom of Winners (KOW) Tracker & Event Planner

Трекер прокачки офицеров, распределения мест на событиях и управления составом альянса для игры Kingdom of Winners.

---

## Быстрый старт

### Вариант 1: Запуск через Docker Compose (рекомендуется)

Требования: установленный Docker и Docker Compose.

1. Запустите контейнер в фоновом режиме:
   ```bash
   docker compose up -d --build
   ```
2. Откройте приложение в браузере:
   ```
   http://localhost:3000
   ```
3. База данных SQLite сохраняется на хост-машине в каталоге `./data/kow.db` благодаря volume mapping (`./data:/app/data`), поэтому данные не теряются при перезапусках или обновлениях контейнера.

Остановка контейнера:
```bash
docker compose down
```

---

### Вариант 2: Локальный запуск без Docker

Требования: Node.js 22+ (используются встроенные модули `node:sqlite` и `node:crypto`, внешние зависимости не требуются).

1. Запустите сервер:
   ```bash
   npm start
   # или напрямую:
   node server.js
   ```
2. Откройте в браузере:
   ```
   http://localhost:3000
   ```
   *(Порт можно переопределить через переменную окружения `PORT=8080 node server.js`)*.

## Учетные записи и роли (RBAC)

В системе реализовано 3 уровня ролей:

1. **R5 (Глава альянса / Администратор)**:
   - Полный доступ ко всем функциям трекера.
   - Управление пользователями и их ролями (повышение R3 до R4/R5).
   - Управление справочником офицеров и типами игровых событий.
   - Экспорт и импорт полной базы данных в формате JSON.
2. **R4 (Офицер / Военком)**:
   - Подтверждение (Approve) и отклонение (Reject) заявок на регистрацию новых игроков.
   - Управление списком игроков альянса, редактирование параметров бойцов.
   - Создание и планирование событий, запуск алгоритма Smart AutoPick для распределения призовых мест.
   - Фиксация результатов событий и закрытие отчетов.
3. **R3 (Боец / Игрок)**:
   - Доступ к **Личному кабинету** (`/api/my-profile`).
   - Самостоятельное обновление уровней штаба, VIP, Сектора Конфиденциальности, запасов купонов и фрагментов.
   - Актуализация текущих звезд и прогресса офицеров.
   - Подача заявок на участие в предстоящих событиях альянса с указанием желаемого места и целевого офицера.
   - Внесение отчета о фактически занятом месте после завершения события.

## Начальный доступ по умолчанию

При первом старте система автоматически инициализирует SQLite базу и создает учетную запись администратора (R5):

- **Логин**: `admin`
- **Пароль**: `admin123`
- **Роль**: `R5` (Лидер альянса)

> [!IMPORTANT]
> Настоятельно рекомендуется сменить пароль учетной записи `admin` сразу после первого входа в систему через личный профиль или панель управления пользователями!

## Процесс регистрации и подтверждения игроков

1. **Саморегистрация игрока**:
   - На экране входа игрок переходит на вкладку **«Регистрация»**.
   - Указывает имя пользователя, пароль, игровое имя (никнейм) и уровень штаба.
   - Если офицеры уже завели карточку игрока в системе, игрок может связать свою учетную запись с существующим профилем.
   - При отправке создается заявка со статусом `pending`. До подтверждения офицерами вход в систему невозможен.

2. **Подтверждение чиновниками (R4 / R5)**:
   - Офицер или Лидер заходит в раздел **«Пользователи»**.
   - В списке заявок отображаются новые игроки, ожидающие подтверждения.
   - Доступны действия:
     - **Одобрить (Approve)**: аккаунту присваивается роль `R3` (Боец), игрок получает доступ к Личному кабинету.
     - **Отклонить (Reject)**: заявка удаляется из системы.
   - Лидер (R5) может в любой момент изменить роль пользователя (например, повысить активного игрока до R4-офицера).

## Личный кабинет игрока (R3) и система заявок

### Личный кабинет
- Игрок самостоятельно актуализирует параметры:
  - Уровень Штаба;
  - Уровень VIP и Сектора Конфиденциальности (от них рассчитывается ежедневный приток купонов);
  - Количество накопленных универсальных купонов и осколков.
- Для каждого офицера указываются текущие звезды (1★ - 5★) и прогресс купонов до следующей звезды.
- Система автоматически рассчитывает дефицит купонов до полной прокачки и прогнозирует дату закрытия офицера.

### Заявки на события и алгоритм Smart AutoPick
- В разделе событий боец видит предстоящие ивенты (Колесо фортуны, Соревнования офицеров и др.).
- Боец может подать заявку:
  - Указать желаемое место (например, 1-е место, топ-3, или «любое подходящее»);
  - Выбрать целевого офицера.
- Алгоритм **Smart AutoPick** при распределении мест:
  - Учитывает заявки бойцов и их приоритеты;
  - Проверяет реальный дефицит купонов у кандидата (исключает оверфлоу, когда награда превышает нужду игрока);
  - Учитывает поколение штаба и Kill Points при разрешении спорных ситуаций (тай-брейк);
  - Гарантирует уникальность игроков на призовых местах.

## Хранение данных и резервные копии

- База данных SQLite сохраняется в файле `data/kow.db` (при использовании Docker том монтируется в `./data:/app/data`).
- В панели управления доступен полный **JSON Экспорт/Импорт** всей базы данных (игроки, офицеры, события, результаты), позволяющий делать моментальные резервные копии и восстанавливать состояние трекера.
