# Smart Scanner: Распознавание скриншотов профиля и склада (OCR)

## 1. Назначение и цели (Intent & Why)

### Проблема
В мобильной стратегии Kiss of War (и родственных играх) игроки и офицеры альянса регулярно обновляют статистику: текущую мощь (Силу), количество очков за убийства (Kill Points), число уничтоженных войск (Kills) и запасы для прокачки на складе (купоны готовности офицера, медали легендарного офицера, купоны готовности звезд, легендарные звезды I, II, III).
Вбивать вручную многозначные числа (например, `157,660,593` силы или `7,588,164,323` очков за убийства) неудобно, долго и чревато опечатками, а также сложно держать в голове и считать общую сумму очков от разнородных звезд I, II, III с разными номиналами.

### Цель
Реализовать функцию **Smart Scanner (OCR-сканер скриншотов)**, которая позволяет игроку в один клик:
1. Загрузить один или несколько скриншотов из игры (через выбор файлов, Drag-and-Drop или вставку из буфера обмена по `Ctrl+V` / `Cmd+V`).
2. Автоматически распознать данные статистики игрока и запасов склада.
3. Объединить данные с нескольких скриншотов без задвоения и потери информации.
4. Проверить распознанные значения в удобной карточке предпросмотра и применить их в профиль одним кликом.
5. Привести названия запасов склада в интерфейсе и базе данных к точным терминам из игры:
   - **«Купон готовности офицера»** (ранее универсальные купоны).
   - **«Медаль легендарного офицера»** (ранее золотые пазлы/медали).
   - **«Купон готовности звезды»** (купоны для звезд).
   - **«Легендарная звезда I»** (номинал **110** очков звезд).
   - **«Легендарная звезда II»** (номинал **420** очков звезд).
   - **«Легендарная звезда III»** (номинал **960** очков звезд).
   - **«Сундук выбора»** (ранее сундуки; сохраняется без затирания при сканировании).
6. Автоматически рассчитывать и отображать **сумму очков звезд**:
   $$\text{TotalStarPoints} = (\text{Stars}_1 \times 110) + (\text{Stars}_2 \times 420) + (\text{Stars}_3 \times 960)$$

## 2. Анализ скриншотов и правила распознавания

### А. Скриншоты статистики игрока (Скриншоты 1 и 2)
На скриншотах профиля отображается карточка персонажа на фоне пергамента:
- **Никнейм и альянс:** строка вида `[A433]ranu` -> тег альянса `[A433]`, имя игрока `ranu`.
- **Сила (Power):** строка `Сила: 157,660,593` -> число `157660593`.
- **Уничтожено юнитов (Kills):** строка `Убито: 84,778,517` или `Уничтожено юнитов: 84,778,517` -> число `84778517`.
- **Очки за убийство (Kill Points):** в детальной таблице боевой статистики указано точное число `7,588,164,323`. Парсер отдает приоритет полному числовому значению перед сокращенным `7.6B` из шапки.
- **VIP уровень:** по требованию пользователя **сканером не распознается и не перезаписывается**; игрок указывает свой уровень VIP самостоятельно.
- **Правило дедупликации:** Скриншот 1 (верхняя часть) и Скриншот 2 (прокрутка вниз) содержат повторяющуюся шапку профиля (`ranu`, Сила, Убито, Очки за убийства). Сканер распознает оба скриншота, сопоставляет их по нику/мощи и бесшовно объединяет в единую запись без конфликтов.

### Б. Скриншоты склада (Скриншоты 3 и 4: «Вещи» → «Другие»)
Инвентарь организован в 2-колоночную сетку плиток. На каждой плитке отображается иконка, номинал (в левом верхнем углу иконки), полное текстовое название предмета на русском языке и плашка `В наличии: <число>`:
- **«Купон готовности офицера»:** плитка с текстом «Купон готовности офицера» и «В наличии: 419,202» -> `coupons = 419202`.
- **«Медаль легендарного офицера»:** плитка с текстом «Медаль легендарного офицера» и «В наличии: 2,077» -> `puzzles = 2077`.
- **«Купон готовности звезды»:** плитка с текстом «Купон готовности звезды» и «В наличии: 244,712» -> `starCoupons = 244712`.
- **«Легендарная звезда I» (номинал 110):** плитка с текстом «Легендарная звезда I» и «В наличии: 1,097» -> `legendaryStars1 = 1097`.
- **«Легендарная звезда II» (номинал 420):** плитка с текстом «Легендарная звезда II» и «В наличии: 95» -> `legendaryStars2 = 95`.
- **«Легендарная звезда III» (номинал 960):** плитка с текстом «Легендарная звезда III» и «В наличии: 22» -> `legendaryStars3 = 22`.
- **Расчет суммы очков звезд:**
  Для Скриншотов 3 и 4:
  $$(1097 \times 110) + (95 \times 420) + (22 \times 960) = 120670 + 39900 + 21120 = 181\,690 \text{ очков звезд}.$$
- **«Сундук выбора» (`chests`):** на данных экранах инвентаря отсутствует; при применении результатов сканирования текущее значение `stock.chests` пользователя обязательно сохраняется в неизменном виде (не затирается).
- **Правило дедупликации склада:** Скриншот 3 содержит купоны и медали, Скриншот 4 содержит звезды. Сканер объединяет найденные предметы с нескольких экранов склада в единый объект `stock`, не сбрасывая в ноль уже найденные запасы.

## 3. Схема данных и миграция базы данных SQLite

В таблице `players` базы данных `data/kow.db`:
- Добавляются колонки:
  - `stock_star_coupons INTEGER NOT NULL DEFAULT 0`
  - `stock_legendary_stars_1 INTEGER NOT NULL DEFAULT 0`
  - `stock_legendary_stars_2 INTEGER NOT NULL DEFAULT 0`
  - `stock_legendary_stars_3 INTEGER NOT NULL DEFAULT 0`
- Безопасная автомиграция в `initDb()` (`db.js`) через `PRAGMA table_info(players)`.
- Обновление структуры `stock` в `db.js` и `logic.js`:
  ```javascript
  stock: {
    coupons: Number,
    puzzles: Number,
    starCoupons: Number,
    legendaryStars1: Number,
    legendaryStars2: Number,
    legendaryStars3: Number,
    chests: Number
  }
  ```
- Новая чистая функция в `logic.js`:
  ```javascript
  const STAR_ITEM_VALUES = {
    legendaryStars1: 110,
    legendaryStars2: 420,
    legendaryStars3: 960,
  };

  function calculateTotalStarPoints(stock = {}) {
    const s1 = Math.max(0, Number(stock.legendaryStars1) || 0);
    const s2 = Math.max(0, Number(stock.legendaryStars2) || 0);
    const s3 = Math.max(0, Number(stock.legendaryStars3) || 0);
    return (s1 * 110) + (s2 * 420) + (s3 * 960);
  }
  ```
- Обновление `exportKowJson` и `importKowJson`: сохранение полей `starCoupons`, `legendaryStars1`, `legendaryStars2`, `legendaryStars3` с гарантией обратной совместимости со старыми версиями.

## 4. Архитектура движка распознавания (OCR Pipeline)

### Клиентский OCR на Web Worker
- **Библиотека OCR:** автономный клиентский движок `Tesseract.js` (Web Worker).
  - Скрипт кэшируется через Service Worker для работы оффлайн.
  - В `server.js` добавляется поддержка MIME-типов `application/wasm` (`.wasm`) для локальной раздачи бинарников.
- **Нулевые зависимости бэкенда:** сервер Node.js остается на нативных модулях (`node:http`, `node:sqlite`), тяжелые файлы изображений не передаются на сервер.
- **Canvas-предобработка изображений:**
  - Масштабирование до оптимального разрешения (высота 1600–2400px).
  - Преобразование в градации серого (Grayscale) и адаптивная бинаризация (Thresholding):
    - Для светлого пергамента профиля: повышение резкости и контраста темных шрифтов.
    - Для темного фона склада: контрастирование белого текста меток «В наличии:».
  - Разделение колонок: при обнаружении 2-колоночной сетки склада Canvas делит изображение на левую и правую колонки плиток, гарантируя точную ассоциацию заголовка предмета с соответствующим числом «В наличии:».
- **Математический парсер текста в `logic.js` (чистые функции, UMD-экспорт):**
  - `cleanOcrNumber(str)`: очистка от пробелов, запятых, точек и случайных OCR-артефактов (замена букв `O`/`o` на `0`, `l`/`I` на `1` в числовых блоках).
  - `parseProfileScreenshotText(text)`: извлечение ника, альянса, мощи, убийств и очков за убийства.
  - `parseWarehouseScreenshotText(text)`: извлечение купонов офицера, медалей легендарного офицера, купонов звезд и легендарных звезд I, II, III (с поддержкой римских цифр `I`, `II`, `III` и арабских `1`, `2`, `3`).
  - `mergeScanResults(accumulated, nextScan)`: интеллектуальное слияние данных с нескольких скриншотов без задвоения и без затирания значений.

## 5. Пользовательский интерфейс (UI/UX)

1. **Кнопка вызова сканера:**
   - В шапке блока личного кабинета (`my_cabinet`) и в модальном окне редактирования игрока: кнопка `📷 Smart Scanner`.
2. **Модальное окно `#modal-smart-scanner`:**
   - **Зона загрузки (Dropzone):**
     - Перетаскивание файлов мышью (Drag-and-Drop).
     - Выбор файлов через проводник (поддержка мультивыбора `multiple`).
     - Вставка из буфера обмена по нажатию `Ctrl+V` / `Cmd+V` прямо в окне браузера.
   - **Индикатор обработки:** пошаговый прогресс-бар («Распознавание скриншота 2 из 4...»).
   - **Карточка предпросмотра результатов:**
     - Блок «Статистика персонажа»: Никнейм, Альянс, Сила, Убийства, Очки за убийства (все поля доступны для быстрого редактирования игроком перед подтверждением). Чекбокс `[ ] Обновить никнейм` (защита от случайного переименования).
     - Блок «Запасы склада»:
       - «Купон готовности офицера»
       - «Медаль легендарного офицера»
       - «Купон готовности звезды»
       - «Легендарная звезда I (110)»
       - «Легендарная звезда II (420)»
       - «Легендарная звезда III (960)»
       - Динамическая сводка: `✨ Итого очков звезд: X (110 × N₁ + 420 × N₂ + 960 × N₃)`
     - Напоминание: *«Уровень VIP укажите вручную в личном кабинете»*.
   - **Кнопка действия:** «✓ Применить в профиль» (переносит распознанные значения в поля формы и сохраняет профиль).
3. **Обновление наименований полей склада в интерфейсе:**
   - `Новые купоны` ➔ `Купон готовности офицера`
   - `Новые пазлы` ➔ `Медаль легендарного офицера`
   - `Новые сундуки` ➔ `Сундук выбора`
   - Добавлено поле ➔ `Купон готовности звезды`
   - Добавлен блок ➔ `Легендарные звезды (I, II, III)` с расчетом суммы очков.
