## 1. Цели и Ценность (Goals & Value)

Текущий трекер опирается на упрощенную математическую модель (3 демо-офицера, базовый расчет VIP > 10, ручной ввод каждого ивента и примитивный подбор без учета правил справедливости альянса).  
Цель данной спецификации — обогатить трекер реальными проверенными данными сообщества Kiss of War (KoW) из Fandom Wiki, Discord-серверов и Google Sheets ведущих альянсов:

1. **Реальный реестр легендарных офицеров:** предоставить предзаполненный каталог офицеров по поколениям (Gen 1 – Gen 9) и типам войск, с четким разделением способов прокачки (стандартные купоны против эксклюзивных/пазловых).
2. **Точная шкала VIP и уровней Конфиденциальности:** шкала очков VIP (1–30) и расчет дефицита очков до следующего уровня, приносящего дополнительный золотой пазл в сутки.
3. **Сетка прокачки навыков офицера (5-5-5-5):** детальный расчет 690 медалей до готовности (поддержка формата навыков 5-1-1-1, 5-5-1-1 и т.д.) вместо абстрактного подсчета.
4. **Шаблоны и циклы ротации ивентов:** пресеты типовых ивентов альянса («Король Войны», «Сильнейший Командир») и автоматическая генерация сезонного календаря с 2-недельным шагом.
5. **Правила справедливости альянса (Fair Play & Cooldowns) в автоподборе:** кулдаун на занятие топ-мест (защита от монополизации 1-х мест одними и теми же игроками) и учет участия в жизни альянса.
6. **Рекомендации боевых связок (Meta Officer Pairings):** подсказки оптимального второго офицера (Primary + Secondary) для открытого поля, гарнизона и ралли.

## 2. Предметная модель и данные (Data Models & Constants)

### 2.1. Реестр офицеров (`OFFICER_CATALOG_DATA`)
Каждый офицер описывается структурой:
```javascript
{
  id: string,                 // уникальный слаг, напр. 'rex', 'nathon', 'jessica'
  name: string,               // русскоязычное имя офицера
  type: 'Танк' | 'ПТ' | 'Пехота' | 'Гарнизон' | 'Осада',
  generation: number,         // номер поколения: 1..9
  upgradeType: 'standard' | 'special', // standard: 500 купонов/пазл; special: 0 купонов (только пазлы)
  couponPerPuzzle: number,    // 500 для standard, 0 для special
  medalsBeforeTraining: 690,  // медали на навыки 5-5-5-5
  medalsTraining: 900,        // медали на подготовку (180 уровней * 5)
  medalsTotal: 1590,          // всего медалей
  skills: [1, 1, 1, 1],       // уровни 4 навыков по умолчанию
  avatar: string              // SVG-бейдж или ссылка на иконку
}
```

Базовый список включает ключевых командиров поколений:
* **Gen 1:** Джессика (Танк), Грейс (Танк), Марджори (Пехота), Эвелин (Пехота), Кэтрин (ПТ), Линда (ПТ).
* **Gen 2–3:** Ангел (Танк), Мария (Пехота), Келли (ПТ), Белла (Гарнизон), Виктория (Осада).
* **Gen 4–6:** Оливия (Танк), София (ПТ), Хлоя (Пехота), Зоя (Гарнизон).
* **Gen 7–9:** Генерал Рекс (Танк, Gen 7), Капитан Блэк (ПТ, Gen 7), Адмирал Нейтон (Пехота, Gen 8), Аврора (Гарнизон, Gen 8), Валькирия (Осада, Gen 9).

### 2.2. Шкала VIP и Конфиденциальности (`VIP_TIERS_DATA`)
Таблица порогов очков VIP и ежедневных наград пазлами:
* VIP 1–9: 0 пазлов/сутки.
* VIP 10: 1 пазл/сутки.
* VIP 11: 2 пазла/сутки.
* VIP 12: 3 пазла/сутки.
* VIP 13: 3 пазла/сутки (+1 золотой сундук).
* VIP 14: 4 пазла/сутки.
* VIP 15–30: прогрессивная шкала вплоть до VIP 30 (до 10+ пазлов).

Пороги очков VIP (`vipPointsTable`):
`[0, 200, 700, 2500, 6000, 15000, 35000, 75000, 150000, 300000, 500000, 750000, 1000000, 1500000, 2500000, ...]`.

Функция расчета дефицита VIP:
```javascript
calculateVipDeficit({ currentLevel, currentPoints, targetLevel })
// Возвращает: { pointsNeeded, dailyPuzzlesIncrease, targetLevel }
```

### 2.3. Сетка прокачки навыков 5-5-5-5 (`SKILL_UPGRADE_COSTS`)
Суммарно на закрытие навыков требуется 690 медалей.
Стоимость каждого шага прокачки для 4 навыков (первый уровень каждого навыка открыт):
* Шаги 1 -> 5 для каждого навыка требуют медалей: `[10, 20, 30, 40]`, `[50, 60, 70, 80]`, `[60, 70, 80, 90]`, `[10, 20, 30, 40]` и т.д., суммирующиеся ровно в 690 медалей.
Функция:
```javascript
calculateSkillMedalsProgress(skills = [1, 1, 1, 1])
// Возвращает: { spentMedals, remainingMedals, isMaxSkills }
```

### 2.4. Шаблоны ивентов и генератор расписания
Пресеты типовых ивентов (`EVENT_PRESETS`):
* `king-of-war`: «Король Войны» (каждые 14 дней, призовые места: 1-е: 12500, 2-е: 6500, 3-е: 3500, 4-10-е: 2750).
* `mightiest-commander`: «Сильнейший Командир» (каждые 28 дней, 6 фаз, призовые места: 1-е: 15000, 2-е: 8000, 3-е: 4500, 4-10-е: 3000).

Функция:
```javascript
generateSeasonSchedule({ startDate, cyclesCount, presetId })
// Возвращает массив запланированных ивентов с датами from/to
```

### 2.5. Правила справедливости в автоподборе (Fair Play Rules)
Параметр `cooldownEventsCount` (по умолчанию 1 или 2 ивента):
* Если игрок занял 1-е, 2-е или 3-е место в одном из предыдущих `N` завершенных ивентов того же типа, ему присваивается штраф к приоритету автоподбора при наличии других игроков с достаточным дефицитом купонов.
* Это исключает ситуацию, когда один активный игрок забирает все 1-е места подряд.

## 3. Требования к обратной совместимости (Compatibility)
1. Все существующие профили игроков и их офицеры в `localStorage` должны сохранять корректность (миграция через [`migrateState`](file:///Users/ranunkulus/Downloads/KOW/logic.js#L63)).
2. Если у игрока офицер не имел навыков `skills`, они по умолчанию считаются `[1, 1, 1, 1]`.
3. Все новые функции должны быть чистыми (pure functions) и покрыты модульными тестами в `logic.test.js`.
